# سامانهٔ مدیریت صورت‌جلسه

سامانه‌ای تحت وب برای ثبت و پیگیری جلسه‌ها، صورت‌جلسه‌ها، مصوبه‌ها و اقدام‌های سازمانی. رابط کاربری فارسی و راست‌چین است.

## امکانات

- مدیریت جلسه‌ها، دستور جلسه، موضوع‌ها و جمع‌بندی
- ثبت مصوبه و واگذاری اقدام با مسئول و مهلت
- پیگیری وضعیت اقدام‌ها و اعلان‌ها
- مدیریت افراد، واحدهای سازمانی و کاربران
- پیوست فایل، خروجی Word و گزارش‌ها

## فناوری‌ها

- ASP.NET Web Forms و C#
- .NET Framework 4.7.2
- SQL Server و ADO.NET

## پیش‌نیازها

- Windows و Visual Studio با workload توسعهٔ ASP.NET و وب
- .NET Framework 4.7.2 Developer Pack برای ساخت و اجرای برنامه
- SQL Server با پایگاه داده و ساختار موردنیاز برنامه

> اسکریپت ساخت ساختار پایگاه داده در این مخزن ارائه نشده است؛ پیش از راه‌اندازی، ساختار پایگاه دادهٔ سازگار با نسخهٔ برنامه را آماده کنید.

## راه‌اندازی محلی

1. مخزن را در Visual Studio باز کنید و بسته‌های NuGet تعریف‌شده در `packages.config` را بازیابی کنید.
2. برای اجرای محلی، رشتهٔ اتصال `MeetingDb` را در `Web.config` متناسب با SQL Server خود تنظیم کنید. مقدار پیش‌فرض از احراز هویت ویندوز استفاده می‌کند.
3. برای محیط‌هایی که نباید اعتبارنامه در فایل تنظیمات باشد، متغیر محیطی `MEETINGMINUTES_CONNECTION_STRING` را برای فرایند برنامه تنظیم کنید. این متغیر بر مقدار `MeetingDb` اولویت دارد.
4. پروژه را با پیکربندی `Release` بسازید و در IIS یا IIS Express اجرا کنید.
5. پس از آماده‌شدن پایگاه داده، به `Setup.aspx` بروید و نخستین مدیر سامانه را بسازید. این صفحه پس از ایجاد اولین کاربر، راه‌اندازی مجدد را نمی‌پذیرد.

فایل‌های پیوست و آواتارهای زمان اجرا در `App_Data` نگهداری می‌شوند و عمداً در مخزن ثبت نمی‌شوند.

## ساخت

در سیستم توسعهٔ ویندوزی با ابزارهای Visual Studio:

```powershell
nuget restore MeetingMinutes.csproj
msbuild MeetingMinutes.csproj /t:Build /p:Configuration=Release
```

جریان کاری GitHub Actions نیز همین پروژه را روی Windows و در حالت `Release` می‌سازد.

## استقرار

- برای اتصال پایگاه داده از حساب کم‌دسترسی استفاده کنید؛ حساب مدیر SQL را در تنظیمات برنامه قرار ندهید.
- مقدار `MEETINGMINUTES_CONNECTION_STRING` را از تنظیمات امن محیط استقرار فراهم کنید.
- سایت را پشت HTTPS منتشر کنید. تبدیل `Web.Release.config` کوکی Forms Authentication را در انتشار Release به HTTPS محدود می‌کند.
- دسترسی نوشتن برنامه به `App_Data` را فقط به هویت برنامه محدود کنید.
- نسخهٔ پشتیبان پایگاه داده و فایل‌های `App_Data` را جداگانه مدیریت کنید.
